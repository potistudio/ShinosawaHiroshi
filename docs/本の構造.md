## 本の構造

```
my-book/
  book.json                 # 書名・著者・判型などの組版設定
  01-はじめに.md            # ページ
  02-第一章 はじまり/       # 章（ディレクトリ）
    index.md                # 章そのものの本文
    01-小さな発見.md
  _images/                  # 貼り付けた画像の保存先
```

- 並び順はファイル名先頭の番号で決まる。番号はサイドバーの「上へ / 下へ」で自動的に振り直される。
- サイドバーに表示されるのは、番号と `.md` を除いた名前。
- `.` または `_` で始まるファイル・フォルダは本の構成に含めない。
- 最上位の要素（ページ・章）は組版時に改ページされる。

## 機能

- **編集**: Milkdown (Crepe) による WYSIWYG 編集。入力は自動保存される。
- **数式**: `$...$`（インライン）と `$$ ... $$`（ブロック）を KaTeX で描画。
- **組版**: Paged.js によるページ分割。扉・目次（ページ番号付き）・柱・ノンブル・章ごとの改ページ。
  判型（A4 / B5 / A5 / B6 / 文庫 / 新書）、文字サイズ、行間、余白を画面上で変更でき、`book.json` に保存される。
- **出力**: 組版画面の「印刷 / PDF」から印刷、または PDF として保存。
- 削除したページは OS のごみ箱へ移動する。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `src-tauri/src/lib.rs` | ファイル操作コマンド（一覧・読み書き・名前変更・ごみ箱） |
| `src/lib/fs.ts` | Rust コマンドの呼び出しとパス操作 |
| `src/lib/book.ts` | 本の設定、ページの追加・名前変更・並べ替え |
| `src/lib/layout.ts` | Markdown → 本の HTML と組版 CSS |
| `src/lib/Editor.svelte` | WYSIWYG エディタ |
| `src/lib/Preview.svelte` | 組版プレビューと設定 |
| `src/lib/Sidebar.svelte` | ページツリー |
| `src/App.svelte` | 画面全体と保存処理 |
